# 20_VERSIONED

歷史版本文件區。

這裡保存具有明確形成時間、版本號或歷史研究語境的文件。封存不是否定，而是防止舊版本與現行定義混讀。

## 目錄

- `20260828/`：Construction Framework v1.1、Construction Unit Presentation Conditions、Computational Space Specification 等早期規格。
- `20260906/`：Qualification 理論與相關聊天室收斂文件。

## 使用方式

閱讀歷史推導、比較概念如何演化、追蹤定義變更時使用本區。

不要因為某文件位於版本區，就直接把它視為錯誤；也不要因為它是早期版本，就把它當成現行定義。
