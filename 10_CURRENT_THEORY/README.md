# 10_CURRENT_THEORY

目前 Construction 理論的工作區。

這裡只放「目前仍被採用、正在使用，或作為當前理論基準」的文件，不以文件日期本身決定地位。

## foundation/

Construction Framework 與構築單位成立／表示條件的核心理論文件。

## formalization/

目前型別優先的形式化工作。這些文件仍可能存在未解決的型別、語義或定義衝突，因此「位於 current」不代表「已證明」。

## appendices/

支援當前理論的局部推導與附錄，例如展開相對性、錨點必要性。

## 重要原則

較新的研究若改變舊定義，不覆寫歷史文件；只把新的工作標成當前版本，並在研究紀錄中保留演化關係。
