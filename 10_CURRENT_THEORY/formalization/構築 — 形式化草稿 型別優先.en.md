## 1. Underlying Sets

S  : Set,  S ⊆ I              the retained information structure
Θ  : Set                      the set of topics

**Type determined.** `S ⊆ I` is consistent across all existing documents, with no divergence.

**Note**: This draft does not assume that I is finite. If I is infinite, the existence conditions for MCS are a pending proof item under STATUS §2.3.

## 2. Establishment Decision Q

### 2.1 Codomain

```text
Q : ⟨T, S, C, K⟩ → 𝔹        𝔹 = {Established, Not Established}
```

**Basis**: The proposer explicitly stated in this round — “K, for the topic invariant, has only two values: established and not established.”

**Conflict already flagged (STATUS §4.5)**: The Kleene tables in the implementation, 《AI 結構化理解》§4, and 《測試計畫》T1.1 all use three values (ESTABLISHED / NOT\_ESTABLISHED / UNKNOWN).

**Treatment in this draft**: The codomain is written as 𝔹, with a note that the computational upper-bound argument in Appendix B §11.1 requires “I have not finished checking” to be expressible, which in turn requires a third value. **The binary-versus-trinary choice remains undecided; this draft does not force a choice.**

### 2.2 Parameter Types

```text
T : [Missing]                 target structure
S : Set                       ✓ determined
C : [Missing]                 Context
K : [Missing]                 see §3
```

**Of the four parameters, only the type of S is determined.** This is the largest gap in the current formalization; this is not an exaggerated statement.

## 3. K — Primary Gap

### 3.1 Three Existing Uses, with Mutually Incompatible Types

| Source | Role of K | Implied type |
| ---------------- | ---------------- | ----------------- |
| 《數學表示》第二式 | Parameter of Q, parallel to T, S, and C | A **value** |
| This round: “the topic as the anchor of this multidimensional unit” | Localization | A **point** |
| This round: returns established / not established | Decision | A **function** `I ⇀ 𝔹` |

**The three types — value, point, and function — are different.** Before the type is determined, Q can only be written as notation, not as a definition.

### 3.2 What Can Be Written in This Round

The proposer supplied one computable component in this round:

```text
exists_theme : Θ ⇀ 𝔹          “whether the topic exists under the current use of K's description”
```

**Type determined; can be written.**

But its scope must be explicitly stated:

```text
exists_theme(θ) = Not Established  ⟹  Q(T,S,C,K) = Not Established
exists_theme(θ) = Established     ⟹  [Q's value remains undetermined]
```

That is: **the existence of a topic is a necessary condition for establishment, not a sufficient condition.** It is a threshold, not a complete criterion.

### 3.3 Rejected Candidates (List Only the Type-Level Reasons; Do Not Rewrite Them)

| Candidate | Type-level problem |
| -------------- | ---------------------------------------- |
| K = [Invariant](不變詞) | An invariant is a unit; K must perform a decision; a unit does not perform decisions |
| K ⊆ S | Q treats S and K as independent parameters; if K ⊆ S, then `∄S′ ⊊ S` may remove K |
| K = Task Purpose | This collapses back into T; Q becomes minimization of T relative to T |
| K = [Anchor Ontology](錨本體) | Anchor Ontology has been established in this round as methodology, not a unit (see §5) |

## 4. [Minimality](極小性)

### 4.1 Two Non-Equivalent Definitions (Retained Verbatim from STATUS §4.6)

```text
(M1)  Q(T,S,C,K)=Established  ∧  ∄ S′ ⊊ S : Q(T,S′,C,K)=Established
(M2)  Q(T,S,C,K)=Established  ∧  ∀ x ∈ S  : Q(T, S∖{x}, C, K)=Not Established
```

**M1 ⟺ M2 only if Q is monotonic.** The existence of the Q7 Contradiction category indicates that Q is non-monotonic (adding information may destroy establishment), so the two actually diverge.

**New criterion introduced in this round**: Appendix B §4.3 records “明確增值” (explicit added value) as a **marginal quantity**, and order affects the result. Marginality naturally falls on the M2 side.

**If M2 is adopted**: The non-uniqueness of MCS has three sources — (1) multiple minimal solutions under the same K (《必要性》v3 §7.7); (2) changing K changes the MCS (this round); (3) selecting in different orders produces different results (this round).

### 4.2 MCS Notation

```text
MCS : ⟨T, I, C, K⟩ → 𝒫(I)
S = MCS(T | I, C, K)
```

**The type can be written** (the codomain is the power set of I because the solution is non-unique; if uniqueness were assumed, it would be a mapping to a subset of I, but uniqueness has already been rejected).

**However, it depends on the three gaps in §2.2.** The notation is valid; the definition is not.

## 5. Current Status of the First Equation

### 5.1 Original Equation

```text
A  --θ-->  I(θ)  --P-->  S
A = Anchor Ontology,  θ = Topic,  I(θ) = invariant corresponding to the current topic,  P = Anchor
```

### 5.2 Parts Rejected in This Round

| Item | Status |
| ------------------------- | ------------------------------------------------- |
| `A` in the equation | **Invalid**. Anchor Ontology has been established in this round as **methodology**, not a unit, and therefore cannot be an item within the equation. The methodology generates this equation; it is not part of the equation |
| `I(θ) ↔ θ` | **Withdrawn**. The invariant is now defined in this round as a multidimensional-domain unit that “neither corresponds nor makes decisions” |
| `I(θ₁) → I(θ₂)` (the invariant changes when the topic changes) | **Direction reversed**. The invariant itself does not change; what changes is which subset is selected |
| `P` = [Anchor](錨點) | Retained |

### 5.3 What Remains

```text
θ  ∈ Θ                        Topic                         ✓
Inv : Set                     invariant (unchanging multidimensional-domain unit)   ✓ type determined
sub : Θ → 𝒫(Inv)             subset selection (what changes with the topic)         ✓ type writable
P : [Missing]                Anchor                       type not determined
```

**`sub`** is **the only thing rescued from the remains of the first equation in this round that has a determined type.**

### 5.4 Symbol Conflict Between P and K [Undecided]

If K = the anchor of the topic (this round), and P = [Anchor](錨點) in the first equation, then **K and P are the same thing**.

However, P's role in the first equation is “the localization of the topic onto the structure,” while K's role in the second equation is “the criterion.”

**The same symbol is performing different functions in the two equations.**

This draft does not resolve the conflict; it is listed as a gap.

## 6. The Two Chains — The Clearest Part at the Type Level in This Round

### 6.1 [Narrative Chain](敘事鏈)

```text
Narr : dependency relation over sequence
Narr ⊆ U × U                  U is the set of information units
```

Properties (established in this round):

- **Does not judge right or wrong.** It only expresses “this comes after that, relying on that.”
- There is only **order**, not temporal sequence — the index is a sequence number `n ∈ ℕ`, not a timestamp.
- **Linear cost**: each step is fixed; chain length is the cost.

**Writable.** A dependency relation is a standard binary relation, so there is no type dispute.

**Undetermined**: stopping condition. This round initially defined it as “added value reaches zero,” then changed it to “dependency,” after which that stopping condition became invalid; the proposer later supplied “according to the relationship between the Narrative Chain and the Logic Chain,” which must be written as **dynamics** (alternating operation), rather than as a definition (mutual definition), otherwise it becomes circular. **The formalization of the dynamics is not included in this draft.**

### 6.2 [Logic Chain](邏輯鏈)

```text
Align : U × Θ × Θ ⇀ 𝔹
Align(x, θ₁, θ₂) = Established  ⟺  x has the same substructure identifiable under θ₁ and θ₂
```

**Basis**: The proposer stated in this round — “For each piece of information, whether the same substructure can be identified for alignment under different topics.”

**Type determined; can be written.** This is the most highly formalized part among the new content introduced in this round.

**The definition of a “reasonable observation node” can therefore be written:**

```text
reasonable(θ) ⟺ ∃ x ∈ U, ∃ θ' ≠ θ : Align(x, θ, θ') = Established
```

**Cost**: Pairwise comparison across topics; with m topics this is O(m²). **This follows from the definition, not from an implementation constraint.**

### 6.3 Asymmetry Between the Two Chains (At the Type Level)

| Type | Cost | Quantity |
| --------- | ---------------------- | -- |
| Narr | `⊆ U × U`, binary relation | Linear | Single |
| Align | `U × Θ × Θ ⇀ 𝔹`, ternary partial function | Quadratic | Multiple when there are multiple topics |

**The asymmetry arises from the types themselves, not from an additional setting.** This is a substantive result of this round.

## 7. [Drift](偏移)

### 7.1 Definition (Final Version in This Round)

```text
drift ⟺ Narr cannot connect when the topic transitions (Construction cannot be completed)
```

**Withdrawn**: using “whether the party declares a change” as the antecedent (Appendix A §4.3). The criterion has been changed to observing Narr, without asking the person.

**Withdrawn**: “all Logic Chains fail ⟹ [Drift](偏移).” Reason: the existence of subsets and subnodes is observed and does not disappear; a broken Logic Chain only means that this instance cannot be matched.

### 7.2 Type

```text
drift : 𝔹                     binary, judging “this moment”
```

Adding recovery does not affect the binary nature — recovery occurs later and is a determination at another moment.

### 7.3 Unresolved Exhaustiveness Problem

If establishment can be restored by **changing the invariant** when the connection fails (Appendix B §11.6), then the strict definition of drift should be:

```text
drift ⟺ ∀ v ∈ Inv_array : Narr cannot connect under v
```

**This requires exhaustive traversal of `Inv_array`.** The exhaustiveness problem has not disappeared; it has merely moved from the Logic Chain to the invariant array.

**A safeguard clause is also required**: failure to find ≠ non-existence (Unknown ≠ Unexplained, 《解釋報告資料總篇》§22). Without this clause, verification of `∀` will treat “not finished searching” as “all are not established.”

## 9. Current Summary

**Expressions that can be written with determined types**: `S ⊆ I`, `sub : Θ → 𝒫(Inv)`, `Narr ⊆ U × U`, `Align : U × Θ × Θ ⇀ 𝔹`, `reasonable(θ)`, `exists_theme : Θ ⇀ 𝔹`, `drift : 𝔹`.

**Only notation, without definitions**: `Q`, `MCS`. The reason is that three of the four parameter types remain undetermined (§8.1).

**Removed from the first equation**: `A` (methodology does not enter the equation), `I(θ) ↔ θ` (correspondence withdrawn).

**Honest assessment**: The formalization of the two chains produced in this round is **more advanced than** the core Q/MCS. The core equations are currently empty shells — this is exactly the state referred to as “content parasitism” in STATUS §4.1. This draft does not alter that state; it only marks the gaps.

**Implication for publication**: The current material is insufficient to support the core chapter of a formalization paper. What it can support is an article on **problem definition and type analysis** — that would be honest and valuable, but it is not “the mathematical representation of Construction.”
