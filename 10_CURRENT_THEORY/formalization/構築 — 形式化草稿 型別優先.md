# 構築 — 形式化草稿（型別優先版）

**建立日期**：2026-09-07
**文件版本**：草稿 v0.1
**文件性質**：新增草稿。**不取代、不覆寫《構築成立基準與最小成立結構的數學表示》或任何既有文件。**

**寫作原則**：只寫**型別確定**的部分。型別不確定者留空並標明缺什麼。
**不涉及數值。** 本文件所有內容為結構與型別，無任何量化。

## 0. 記法約定

| 記法 | 意義 |
|---|---|
| `X : T` | X 的型別為 T |
| `𝒫(X)` | X 的冪集 |
| `X ⇀ Y` | X 到 Y 的偏函數 |
| `⟨…⟩` | 有序元組 |
| **［缺］** | 型別未定，本草稿不寫 |

## 1. 底層集合

```
I  : Set                      目前可取得的資訊集合
S  : Set,  S ⊆ I              保留下來的資訊結構
Θ  : Set                      主題的集合
```

**型別確定。** `S ⊆ I` 在所有既有文件中一致，無分歧。

**注意**：本草稿不假設 I 有限。I 無限時 MCS 的存在條件屬 STATUS §2.3 待證項。

## 2. 成立判定 Q

### 2.1 值域

```
Q : ⟨T, S, C, K⟩ → 𝔹        𝔹 = {成立, 不成立}
```

**依據**：本輪提出者明確陳述 ——「K 對主題不變詞只有成立與不成立兩個值」。

**已標衝突（STATUS §4.5）**：implementation、《AI 結構化理解》§4、《測試計畫》T1.1 的 Kleene 表皆為三值（ESTABLISHED / NOT_ESTABLISHED / UNKNOWN）。

**本草稿的處置**：值域寫為 𝔹，但附註 —— 附錄 B §11.1 的計算上限論證要求「我沒查完」必須可表達，那需要第三個值。**二值與三值的取捨未裁決，此處不強行選邊。**

### 2.2 參數型別

```
T : ［缺］                    目標結構
S : Set                       ✓ 確定
C : ［缺］                    Context
K : ［缺］                    見 §3
```

**四個參數中只有 S 的型別是確定的。** 這是目前形式化最大的空缺，非誇張陳述。

## 3. K —— 主要缺口

### 3.1 現有的三種用法，型別互不相容

| 出處 | K 的角色 | 蘊含型別 |
|---|---|---|
| 《數學表示》第二式 | Q 的參數，與 T、S、C 並列 | 一個**值** |
| 本輪：「主題這個多維單位的錨點」 | 定位 | 一個**點** |
| 本輪：回傳成立／不成立 | 判定 | 一個**函數** `I ⇀ 𝔹` |

**值、點、函數三者型別不同。** 在型別確定之前，Q 無法寫成定義，只能寫成記號。

### 3.2 本輪可寫的部分

提出者本輪給出一個可算的成分：

```
exists_theme : Θ ⇀ 𝔹          「當下使用的 K 的形容，主題是否存在」
```

**型別確定，可寫。**

但須明記其範圍：

```
exists_theme(θ) = 不成立  ⟹  Q(T,S,C,K) = 不成立
exists_theme(θ) = 成立    ⟹  ［Q 的值未定］
```

即：**主題存在是成立的必要條件，不是充分條件。** 它是門檻，不是完整判準。

### 3.3 已排除的候選（不重寫，僅列型別理由）

| 候選 | 型別上的問題 |
|---|---|
| K = [[不變詞]] | 不變詞是單位，K 需為判定；單位不判定 |
| K ⊆ S | Q 視 S 與 K 為獨立參數；若 K ⊆ S，`∄S′ ⊊ S` 可能削去 K |
| K = 任務目的 | 會塌回 T，Q 變成相對 T 對 T 極小化 |
| K = [[錨本體]] | 錨本體本輪已定為方法論，非單位（見 §5） |

## 4. [[極小性]]

### 4.1 兩個不等價的定義（STATUS §4.6，原樣保留）

```
(M1)  Q(T,S,C,K)=成立  ∧  ∄ S′ ⊊ S : Q(T,S′,C,K)=成立
(M2)  Q(T,S,C,K)=成立  ∧  ∀ x ∈ S  : Q(T, S∖{x}, C, K)=不成立
```

**M1 ⟺ M2 僅當 Q 單調。** Q7 Contradiction 類別的存在表示 Q 非單調（加入資訊可能破壞成立），故兩者實際分岔。

**本輪新增的判準**：附錄 B §4.3 記載「[[明確增值]]」為**邊際量**，順序影響結果。邊際性天然落在 M2 一側。

**若採 M2**：MCS 的非唯一性有三個來源 —— (1) 同一 K 下多個極小解（《必要性》v3 §7.7）；(2) K 換掉則 MCS 換（本輪）；(3) 選取順序不同則結果不同（本輪）。

### 4.2 MCS 記號

```
MCS : ⟨T, I, C, K⟩ → 𝒫(I)
S = MCS(T | I, C, K)
```

**型別可寫**（值域為 I 的冪集，因非唯一 —— 若採唯一則為 `→ I` 的子集，但唯一性已被否定）。

**但依賴 §2.2 三個缺口。** 記號成立，定義不成立。

## 5. 第一式的現況

### 5.1 原式

```
A  --θ-->  I(θ)  --P-->  S
A = 錨本體,  θ = 主題,  I(θ) = 對應當前主題的不變詞,  P = 錨點
```

### 5.2 本輪推翻的部分

| 項 | 狀態 |
|---|---|
| `A` 在式中 | **不成立**。錨本體本輪定為**方法論**，不是單位，不能作為式中一項。方法論產生此式，不在式內 |
| `I(θ) ↔ θ` | **已撤**。不變詞本輪定為「不對應也不判定」的多維領域單位 |
| `I(θ₁) → I(θ₂)`（主題變則不變詞變） | **方向反轉**。不變詞本身不變化，變的是取哪個子集 |
| `P` = [[錨點]] | 保留 |

### 5.3 剩下什麼

```
θ  ∈ Θ                        主題            ✓
Inv : Set                     不變詞（不變的多維領域單位）   ✓ 型別確定
sub : Θ → 𝒫(Inv)             取子集（隨主題而變的是這個）  ✓ 型別可寫
P : ［缺］                    錨點            型別未定
```

**`sub` 是本輪唯一從第一式殘骸中救出來的、型別確定的東西。**

### 5.4 P 與 K 的符號衝突【未決】

若 K = 主題的錨點（本輪），而第一式中 P = [[錨點]]，則 **K 與 P 是同一個東西**。

但 P 在第一式的角色是「主題落到結構的定位」，K 在第二式的角色是「判準」。**同一符號在兩式中做不同的事。**

此衝突本草稿不解，列為缺口。

## 6. 兩條鏈 —— 本輪型別最清楚的部分

### 6.1 [[敘事鏈]]

```
Narr : 順序上的依存關係
Narr ⊆ U × U                  U 為資訊單位集合
```

性質（本輪已定）：

- **不判對錯**。只表達「這個在那個之後、靠著那個」
- 只有**順序**，無時序 —— 索引為序號 `n ∈ ℕ`，非時間戳
- **線性成本**：每步固定，鏈長即成本

**可寫。** 依存關係是標準的二元關係，型別無爭議。

**未定**：停止條件。本輪一度定為「增值歸零」，後改為「依存」之後該停止條件失效；提出者後給「依照敘事鏈與邏輯鏈的關聯性」，須寫成**動力學**（交替進行）而非定義（互相定義），否則循環。**動力學的形式化本草稿未寫。**

### 6.2 [[邏輯鏈]]

```
Align : U × Θ × Θ ⇀ 𝔹
Align(x, θ₁, θ₂) = 成立  ⟺  x 在 θ₁ 與 θ₂ 下可找出同樣的子結構
```

**依據**：本輪提出者陳述 ——「每一個資訊，在不同的主題上，是否可以找出同樣的子結構進行對齊」。

**型別確定，可寫。** 這是本輪新增內容中形式化程度最高的一條。

**「合理觀察節點」的定義因此可寫**：

```
reasonable(θ) ⟺ ∃ x ∈ U, ∃ θ' ≠ θ : Align(x, θ, θ') = 成立
```

**成本**：跨主題兩兩比對，主題數 m 時為 O(m²)。**此為定義帶來的，非實作限制。**

### 6.3 兩條鏈的不對稱（型別層面）

| | 型別 | 成本 | 數量 |
|---|---|---|---|
| Narr | `⊆ U × U`，二元關係 | 線性 | 單一 |
| Align | `U × Θ × Θ ⇀ 𝔹`，三元偏函數 | 平方 | 多主題時多條 |

**不對稱是型別本身帶來的，不是附加設定。** 這是本輪的實質結果。

## 7. [[偏移]]

### 7.1 定義（本輪最終版）

```
drift ⟺ 主題轉移時 Narr 接不上（構築無法完整）
```

**已撤**：以「當事人是否宣告更換」為前件（附錄 A §4.3）。判準改為觀測 Narr，不問人。
**已撤**：「全部邏輯鏈不成立 ⟹ [[偏移]]」。理由：子集合與子節點是觀測到的存在，不會遺失；邏輯鏈斷只表示這次對不上。

### 7.2 型別

```
drift : 𝔹                     二值，判的是「這一刻」
```

補回不影響二值性 —— 補回發生在之後，是另一個時刻的判定。

### 7.3 未決的窮盡問題

若接不上時可**換不變詞重新成立**（附錄 B §11.6），則嚴格的偏移定義應為：

```
drift ⟺ ∀ v ∈ Inv_array : Narr 在 v 下皆接不上
```

**這需要窮盡 `Inv_array`。** 窮盡問題並未消失，只是從邏輯鏈轉移到不變詞陣列上。

**且需保護條款**：找不到 ≠ 不存在（Unknown ≠ Unexplained，《解釋報告資料總篇》§22）。無此條款，`∀` 的驗證會把「沒找完」當成「都不成立」。

## 8. 缺少的材料 —— 清單

按阻塞程度排序。**前三項不補齊，Q 與 MCS 無法從記號變成定義。**

### 8.1 阻塞級

| # | 缺什麼 | 為什麼是阻塞 | 補齊的最低要求 |
|---|---|---|---|
| **1** | **K 的型別**：值／點／函數，三選一 | Q 的參數位置需要確定型別。三種都出現過且互不相容 | 選一個。若選函數，須給定義域與值域；若選點，須說明點如何參與判定 |
| **2** | **T 的型別**：目標結構是什麼 | Q 的第一參數。「結構」在全部文件中未給型別 | T 是 I 的子集？是 U 上的關係？是命題？三者皆可，須擇一 |
| **3** | **C 的型別**：Context 是什麼 | Q 的第三參數。全部文件僅用其名 | 是參數集？是 I 的另一個子集？是索引？ |

### 8.2 結構級

| # | 缺什麼 | 影響 |
|---|---|---|
| 4 | **Q 的值域**：二值或三值 | §2.1。三值才能表達「沒查完」，而 §7.3 需要它 |
| 5 | **P 與 K 是否同一** | §5.4。同一則第一式與第二式須合併改寫；不同則須說明兩者關係 |
| 6 | **「形容單位」能否進入參數位置** | 提出者本輪陳述「這些都是形容單位，不是固定單位」。形容進不了參數位置。若採此立場，全部形式化須降級為**示意**，不能作為定義 |
| 7 | **極小性採 M1 或 M2** | §4.1。本輪的邊際性論證偏向 M2 |

## 9. 現況總結

**可寫成型別確定的式子者**：`S ⊆ I`、`sub : Θ → 𝒫(Inv)`、`Narr ⊆ U × U`、`Align : U × Θ × Θ ⇀ 𝔹`、`reasonable(θ)`、`exists_theme : Θ ⇀ 𝔹`、`drift : 𝔹`。

**只有記號、沒有定義者**：`Q`、`MCS`。原因是四個參數中三個型別未定（§8.1）。

**已從第一式移除者**：`A`（方法論不入式）、`I(θ) ↔ θ`（對應已撤）。

**誠實的評估**：本輪產生的兩條鏈的形式化程度**高於**核心的 Q/MCS。核心式子目前是空殼 —— 這正是 STATUS §4.1「內容寄生」所指的狀態，本草稿未能改變，只是把空缺標出來。

**對發表的意涵**：現在的內容不足以支撐形式化論文的核心章節。可支撐的是一篇**問題界定與型別分析**的文章 —— 那是誠實的，也是有價值的，但它不是「構築的數學表示」。
