# CEGS｜人類快速入口

## 這是什麼？

CEGS 是 Construction 研究的公開研究與實驗載體。它保存目前理論、歷史版本、持續研究與工程實驗，但 CEGS 本身不等於 Construction。

Construction 目前研究的核心問題是：

> 當多維資訊不能被完整保留時，什麼結構必須保留，才能讓目標仍可理解、成立、比較、追索與重新判定？

目前工作重心是「適應性結構與主題性不變」，而不是尋找唯一形式。

## 目前讀哪裡？

第一次閱讀只需要三份：

1. `10_CURRENT_THEORY/foundation/構築（Construction）：多維資訊概念中的適應性結構與主題性不變.md`
2. `10_CURRENT_THEORY/foundation/目前研究核心第一版：內容資料正式紀錄.md`
3. `30_ACTIVE_RESEARCH/construction/README.md`

第一份回答「現在的 Construction 是什麼」。
第二份回答「目前有哪些核心結構候選」。
第三份回答「現在還有哪些問題沒有結束」。

## 目前最重要的結構

```text
Purpose + Goal + Conditions
        ↓
Adaptive Construction
        ↓
Thematic Invariance
```

目前另有一個重要跨層補充：

```text
State
  ↓
Representation
  ↓
Interpretation
```

它表示：主體的狀態經過外化形成可取得的表示，接收者再根據表示形成理解；這不是透明傳輸，也不宣稱為本體論結論。

## 目前十四項核心候選

Topic / Invariant / Relation / Condition / Validity / Observation / Interpretation / Necessary Structure / Sufficiency / Expansion / Anticipation / Continuation / State / Boundary

它們是工作性候選，不是不可再分解的最終基元。

## 研究狀態怎麼看？

- **現行理論**：目前作為理論基準使用。
- **持續研究**：尚未完成、仍在比較或驗證。
- **版本資料**：某個時間點形成的歷史版本。
- **日期證據**：保留當時原始研究狀態。
- **歷史實驗**：工程與實驗證據，不等於理論已被證明。

舊資料不因為新資料出現而刪除；新資料也不因為日期較新就自動正確。
