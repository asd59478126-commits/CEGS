# CEGS | Human Quick Start

## What is this?

CEGS is the public research and experimental repository for the Construction research program. It preserves current theory, historical versions, active research, and engineering experiments. CEGS itself is not identical to Construction.

The current Construction research question is:

> When multidimensional information cannot be preserved in full, what structure must be preserved so that the target can remain understandable, valid, comparable, traceable, and re-qualifiable?

The current focus is adaptive structure and thematic invariance, not a search for one universal form.

## Current central structure

```text
Purpose + Goal + Conditions
        ↓
Adaptive Construction
        ↓
Thematic Invariance
```

There is also an important cross-layer supplement:

```text
State
  ↓
Representation
  ↓
Interpretation
```

It describes how a subject's state can be externalized into an accessible representation, after which another subject forms an interpretation from that representation. This is not treated as transparent transmission or as a final ontological claim.

## Current fourteen core candidates

Topic / Invariant / Relation / Condition / Validity / Observation / Interpretation / Necessary Structure / Sufficiency / Expansion / Anticipation / Continuation / State / Boundary

These are working candidates, not final irreducible primitives.

## How to read research status

- **Current Theory**: currently used as a theory baseline.
- **Active Research**: unresolved, changing, comparative, or validation work.
- **Versioned**: a historical formulation from a defined period.
- **Date Evidence**: preserves the original state of research at a given date.
- **Historical Experiment**: engineering and experimental evidence; not automatic proof of the theory.

Older material is not deleted because newer material exists. Newer material is not automatically more correct because it is newer.

## When engineering evidence matters

Go to `construction_lab/`. It contains earlier Stage 1 implementations, results, run logs, debugging, repair records, and audit material.

Do not treat historical experimental results as automatic validation of Construction.
