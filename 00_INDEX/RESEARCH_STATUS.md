# CEGS Research Status

本目錄是 CEGS 的時間與研究狀態索引。

CEGS 不以單一「最新版」理解全部文件，而是同時保留：

1. 現行理論：目前正在使用或維持的 Construction 理論結構。
2. 版本文件：具有明確歷史時間、版本語境或已被後續研究取代的文件。
3. 持續研究：目前尚未定稿、仍在推導或等待驗證的問題。
4. 歷史實驗：早期 Qualification / Stage 1 實驗與其審計材料。
5. 日期證據：保留特定研究日形成時的原始資料，不以日期目錄直接代替理論分類。

## 目前 Construction 核心基線

現行主體文件：

`10_CURRENT_THEORY/foundation/構築（Construction）：多維資訊概念中的適應性結構與主題性不變.md`

目前核心候選十四項：

`Topic / Invariant / Relation / Condition / Validity / Observation / Interpretation / Necessary Structure / Sufficiency / Expansion / Anticipation / Continuation / State / Boundary`

目前不把十四項視為最終不可再分解的基元集合。

## 新增跨層映射方向

2026-09-12 新增：

```text
Internal State
      ↓
External Representation
      ↓
Interpretation
```

目前研究定位：

- `Internal State ≠ External Representation`
- `External Representation ≠ Interpretation`
- 不把表示理解為透明傳輸。
- 不把理解理解為原始狀態的直接取回。
- 研究形式改變下的 Thematic Continuity。

這是構築研究的跨層結構補充，不暫定為新增核心第十五項，也不宣稱為完整心智或意識本體論。

## 目前持續研究問題

- Q 的二值／三值語義。
- T、C、K、P 的正式型別。
- K 的語義角色是否必須拆分。
- MCS 的最小性條件（M1 / M2）。
- 不變詞、邏輯鏈、敘事鏈的必要性與相互關係。
- Narrative Chain 的停止條件與動力學。
- Correspondence / Symmetry / Alignment 是否構成 Qualification 的共同底層結構。
- Construction 的實際工程收益與可驗證性。
- 記憶當量是否可形成穩定、可操作的工作性尺度。
- 情緒峰值是否具有不可由既有權勢／重要度無損化約的作用。
- 交換治理第一層的「差異 → 交流需求 → 交換需求 → 需求峰值 → 交換判定」是否可形成可操作結構。
- 狀態 → 表示 → 理解之間的主題性連續如何判定。
- Representation 與 Reconstruction 是否需要成為正式跨層結構術語。
- 跨主體映射中哪些資訊改變仍不破壞構築成立。

## 判讀規則

文件較新，不代表理論必然較正確；文件較舊，也不代表內容失效。

日期用來保存形成歷史，研究狀態用來表示目前地位。兩者不可互相取代。

`00_INDEX/CONTENT_CATALOG.md` 是人類／AI 共用的入口目錄；`00_INDEX/AI_INGESTION_GUIDE.md` 定義 AI 讀取時不得扁平化資料層級的規則。
