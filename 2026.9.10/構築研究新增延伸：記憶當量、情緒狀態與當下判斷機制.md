# 構築研究新增延伸：記憶當量、情緒狀態與當下判斷機制

## 一、研究定位

本報告記錄構築（Construction）研究在記憶與情緒相關問題上的近期延伸。

本階段內容目前主要屬於**工作性假設、概念模型與待驗證架構**，不取代構築目前已建立的核心理論，也不宣稱其中任何尚未驗證的機制已經成立。

本次延伸主要處理三個相互關聯的問題：

1. 記憶如何在當前構築中產生實際作用；
2. 如何描述過去資訊進入當下判斷空間的作用程度；
3. 情緒是否能作為記憶重新進入當前構築的觸發條件之一。

目前暫時形成：

\[
\boxed{
\text{Memory Equivalent}
}
\]

\[
\boxed{
\text{Current Judgment Quantity}
}
\]

以及：

\[
\boxed{
\text{Multidimensional Emotional State}
}
\]

三個相關概念。

---

# 二、記憶的重新定位

本研究目前不再將記憶單純理解為資訊保存。

較適合構築的工作性表示為：

\[
\text{Record}
\neq
\text{Memory}
\]

以及：

\[
\text{Memory}
\neq
\text{Current Recall Alone}
\]

記憶真正具有構築意義的條件，是過去形成的資訊或結構能夠在新的時間與情境下再次參與：

\[
\text{Understanding}
\rightarrow
\text{Construction}
\rightarrow
\text{Judgment}
\rightarrow
\text{Selection}
\]

因此，本階段提出：

> **記憶的核心不僅是保留過去，而是使過去仍能參與現在。**

可暫時表示為：

\[
\boxed{
\text{Memory}
\rightarrow
\text{Current Selection}
}
\]

這一命題並不聲稱人類記憶能夠完整保存過去，也不把任何單次回憶視為客觀現實本身。

---

# 三、記憶、記錄與持續參照

在構築架構中，需要區分：

\[
\text{Record}
\]

\[
\text{Retrieval}
\]

\[
\text{Memory Continuity}
\]

三者。

保存某項資訊，只能證明該資訊仍然存在於某個可取得的結構中。

成功取回某項資訊，只能證明它具有某種可檢索性。

只有當過去形成的結構能夠在新的構築中重新定位、重新參照並參與當前判斷時，才開始具備本研究所稱的「記憶連續性」。

因此：

\[
\boxed{
\text{Stored Record}
\neq
\text{Remembered Structure}
}
\]

而：

\[
\boxed{
\text{Remembered Structure}
\rightarrow
\text{Current Participation}
}
\]

則是本階段研究所關注的主要方向。

---

# 四、記憶當量（Memory Equivalent）

基於上述區分，本研究提出「記憶當量」作為工作性術語。

目前暫定定義為：

> **記憶當量，是某一過去形成的資訊或結構，在指定任務、情境、參照與成立條件下，對當前理解、構築與判斷所產生之可等效作用程度。**

其目的不是衡量「保存了多少資料」，而是描述：

> **過去資訊目前仍然能夠作用多少。**

因此：

\[
\text{Information Quantity}
\neq
\text{Memory Equivalent}
\]

以及：

\[
\text{Record Count}
\neq
\text{Memory Equivalent}
\]

同樣：

\[
\text{More Records}
\not\Rightarrow
\text{More Effective Memory}
\]

---

# 五、記憶當量的條件性

記憶當量不被假定為某個記憶項目的固定屬性。

在不同：

\[
\text{Task Purpose}
\]

\[
\text{Task Goal}
\]

\[
\text{Current Context}
\]

\[
\text{Structural Relation}
\]

下，同一記憶結構可能具有不同的實際作用程度。

因此：

\[
ME(x\mid C_1)
\neq
ME(x\mid C_2)
\]

其中：

- \(ME\) 表示 Memory Equivalent；
- \(x\) 表示記憶對象；
- \(C\) 表示當前成立條件或情境。

這符合構築本身的適應性特徵：

\[
\text{Changing Conditions}
\rightarrow
\text{Structural Adaptation}
\]

而同時維持：

\[
\text{Thematic Invariance}
\]

---

# 六、記憶當量與不變詞

構築允許同一主題在不同時間、形式、任務與結構位置中持續存在。

因此必須存在某種可持續參照的結構，使：

\[
C_t
\rightarrow
C_{t+1}
\]

不只是兩個完全獨立的結構。

本研究因此暫定：

\[
\boxed{
\text{Persistent Reference}
}
\]

是跨時間構築連續性的重要條件。

而記憶性結構則可被視為其中一種核心機制。

因此：

\[
\boxed{
\text{Memory Invariant}
}
\]

可以被理解為：

> **在結構發生變化之後，過去形成的對象仍然可以被重新定位、參照與使用。**

其核心不是「內容完全不變」，而是：

\[
\boxed{
\text{Reference Continuity}
}
\]

---

# 七、主題、不變詞、子集合與子結構

目前構築研究已形成：

\[
\text{Theme}
\rightarrow
\text{Invariant}
\rightarrow
\text{Subset}
\rightarrow
\text{Substructure}
\]

的多層結構理解。

在此架構下，同一主題可以在不同位置反覆被引用，並透過不同子集合與子結構進行展開。

例如：

\[
T
\rightarrow
I_1,I_2,\ldots
\rightarrow
S_{ij}
\rightarrow
s_{ijk}
\]

因此，同一主題不需要維持唯一形式。

它可以：

\[
C_1\neq C_2
\]

同時保持：

\[
Theme(C_1)=Theme(C_2)
\]

本階段因此將「記憶」理解為維持這種跨時間與跨結構參照能力的其中一項必要結構。

---

# 八、當下判斷量（Current Judgment Quantity）

記憶當量並不等同於當前實際可用的全部判斷能力。

因此另行提出：

\[
\boxed{
\text{Current Judgment Quantity}
}
\]

其工作性意義為：

> **在特定時間、任務與情境下，系統實際能將多少可取得結構帶入有效判斷的程度。**

因此：

\[
\text{Stored Information}
\gg
\text{Current Judgment Quantity}
\]

完全可以成立。

同樣：

\[
\text{Memory Equivalent}
\gg
\text{Current Judgment Quantity}
\]

也可以成立。

原因在於某些記憶即使存在並具有穩定作用，也未必需要在每一個當下被啟用。

因此本階段暫時區分：

\[
\boxed{
\text{Memory Equivalent}
=
\text{Past Structure's Effective Potential}
}
\]

與：

\[
\boxed{
\text{Current Judgment Quantity}
=
\text{Currently Usable Structural Participation}
}
\]

---

# 九、為什麼代理人數量不能直接等價於認知量

上述概念也適用於代理人系統。

不能直接假設：

\[
1\text{ Agent}=1\text{ Cognitive Equivalent}
\]

也不能假設：

\[
n\text{ Agents}=n\text{ Units of Judgment}
\]

因為代理人輸出可能包含：

\[
\text{Novelty}
\]

\[
\text{Redundancy}
\]

\[
\text{Error}
\]

\[
\text{Overlap}
\]

\[
\text{Structural Contribution}
\]

因此：

\[
\boxed{
\text{Agent Count}
\neq
\text{Effective Cognitive Quantity}
}
\]

這也是後續多代理構築研究中需要先建立「當量」概念，而不是直接使用代理人數量作為能力代理變數的原因之一。

---

# 十、情緒在構築中的暫定定位

本階段暫不把情緒視為構築成立的必要條件。

即：

\[
\text{Construction}
\not\Rightarrow
\text{Emotion Simulation}
\]

因此，AI 若要具有構築能力，並不必然需要模擬人類情緒。

然而，本研究目前提出另一個較弱且較具操作性的假設：

\[
\boxed{
\text{Emotion}
\rightarrow
\text{Memory Trigger}
}
\]

即：

> **情緒可能是促使部分過去結構重新進入當下構築的重要觸發條件之一。**

這裡的情緒並不是記憶本身。

而是：

\[
\text{Emotional State}
\rightarrow
\text{Attention / Priority Shift}
\rightarrow
\text{Memory Re-entry}
\]

---

# 十一、情緒不是單一向量

早期可以將情緒簡化為多維向量，但目前研究傾向暫不固定採用此形式。

原因是情緒狀態可能：

1. 同時具備多個維度；
2. 不同維度之間可能存在非線性關係；
3. 某些狀態可能超過一般交流或情境中的參考峰值；
4. 超峰值本身不必然代表系統失效；
5. 超峰值之後仍需要存在後續處理機制。

因此，目前較適合稱為：

\[
\boxed{
\text{Multidimensional Emotional State}
}
\]

而非預先假定它必然是固定維度向量。

---

# 十二、情緒峰值

本階段暫時提出數種類型的「情緒峰值參照」。

至少包括：

\[
P_{\mathrm{comm}}
\]

一般交流中的情緒表現峰值；

\[
P_{\mathrm{ctx}}
\]

特定情境下所需或可接受的情緒表達峰值；

\[
P_{\mathrm{protect}}
\]

自我保護相關情緒反應的參考峰值。

這些峰值目前不被定義為絕對上限。

較適合理解為：

\[
\boxed{
\text{Reference Peak}
}
\]

即某一情緒狀態的比較基準。

因此完全可能存在：

\[
E>P_{\mathrm{comm}}
\]

甚至：

\[
E>P_{\mathrm{ctx}}
\]

而此時問題不是「是否超出數值上限」，而是：

\[
\boxed{
\text{系統接下來如何處理}
}
\]

---

# 十三、超峰值狀態

當：

\[
E>P
\]

時，本研究目前不把它直接判定為錯誤。

可以暫時將其理解為：

\[
\text{Peak Exceedance}
\]

即情緒狀態超過某一參考峰值。

此後系統可以根據：

\[
\text{Current Context}
\]

\[
\text{Current Goal}
\]

\[
\text{Boundary}
\]

以及：

\[
\text{Current Judgment Quantity}
\]

決定是否：

\[
\text{Reduce}
\]

\[
\text{Delay}
\]

\[
\text{Reconstruct}
\]

\[
\text{Re-route}
\]

\[
\text{Protect}
\]

或採取其他適當處理。

因此目前可提出：

\[
\boxed{
\text{Emotion Peak}
\neq
\text{Absolute Ceiling}
}
\]

而：

\[
\boxed{
\text{Peak Exceedance}
\rightarrow
\text{Handling Selection}
}
\]

是本階段較重要的工作性假設。

---

# 十四、情緒與記憶當量

在目前模型中，情緒最值得研究的地方不是「情緒本身有多少」，而是其是否能改變特定記憶進入當下構築的優先級。

暫時可表示為：

\[
\text{Emotional State}
\rightarrow
\text{Recall Priority}
\rightarrow
\text{Memory Equivalent Activation}
\rightarrow
\text{Current Construction}
\]

因此，同一記憶結構可能在不同情緒與情境下具有不同的當下作用。

例如：

\[
ME_t(x)
<
ME_{t+1}(x)
\]

不必然表示記憶內容發生改變。

它可能只表示：

\[
\text{Current Relevance}
\uparrow
\]

即該記憶在當前條件下被提高了重新參照的優先級。

---

# 十五、情緒不能直接決定記憶真實性

本模型必須維持一條不可壓縮邊界：

\[
\boxed{
\text{Emotion Peak}
\neq
\text{Memory Validity}
}
\]

以及：

\[
\boxed{
\text{Emotional Strength}
\neq
\text{Reality Certainty}
}
\]

高情緒只可以在目前假設中改變：

\[
\text{Attention}
\]

\[
\text{Retrieval Priority}
\]

或：

\[
\text{Memory Re-entry}
\]

不能直接推出：

\[
\text{Truth}
\]

這個限制與構築目前既有的：

\[
\text{Observation}\neq\text{Reality}
\]

以及：

\[
\text{Candidate}\neq\text{Established}
\]

保持一致。

---

# 十六、構築中的記憶功能架構

目前可以暫時形成以下工作性結構：

\[
\boxed{
\text{Past Structure}
\rightarrow
\text{Memory Organization}
\rightarrow
\text{Contextual Trigger}
\rightarrow
\text{Memory Equivalent}
\rightarrow
\text{Current Judgment}
}
\]

其中：

\[
\text{Memory Organization}
\]

描述過去結構如何保持可參照性；

\[
\text{Contextual Trigger}
\]

描述目前情境、任務、刺激或情緒如何提高某些結構的重新進入優先級；

\[
\text{Memory Equivalent}
\]

描述過去結構目前具有多少實際作用；

\[
\text{Current Judgment}
\]

則描述這些結構在當下真正參與多少判斷。

---

# 十七、「構築海馬體」的功能性比喻

本階段可保留「構築海馬體（Construction Hippocampus）」這一名稱作為功能性比喻。

其用途不是宣稱 AI 中存在一個對應於生物學海馬體的器官，而是描述一個功能層：

> **負責將不同時間、不同情境與不同結構位置中的過去資訊重新綁定，使其能再次參與當下構築。**

因此：

\[
\boxed{
\text{Construction Hippocampus}
\neq
\text{Database}
}
\]

而比較接近：

\[
\boxed{
\text{Past Structure}
\rightarrow
\text{Rebinding}
\rightarrow
\text{Current Construction}
}
\]

---

# 十八、與任務態資料庫的差異

任務態資料庫可以保存：

\[
\text{Task State}
+
\text{History}
+
\text{Records}
\]

但資料保存本身不等於認知記憶。

因此：

\[
\boxed{
\text{Task-state Database}
\neq
\text{Cognitive Memory}
}
\]

較合理的理解是：

\[
\text{Task-state Database}
\rightarrow
\text{Potential Memory Source}
\]

而：

\[
\text{Memory Equivalent}
\]

描述其中真正能在當下構築中產生有效作用的部分。

---

# 十九、代理人與記憶當量的關係

若未來構築使用大量代理人，則不能直接使用：

\[
\text{Agent Count}
\]

取代：

\[
\text{Memory Equivalent}
\]

因為不同代理人的輸出可能對同一主題形成：

\[
\text{Repeated Reference}
\]

也可能形成：

\[
\text{Conflicting Construction}
\]

或：

\[
\text{Redundant Expansion}
\]

因此後續系統若需要大規模代理協作，必須先回答：

> **這些代理人的中間結果，有多少真正被保留為可再利用的結構？**

以及：

> **這些結構目前有多少真正進入了當下判斷？**

這正是「記憶當量」與「當下判斷量」可能提供的共同尺度。

---

目前可以將本階段模型濃縮為：

\[
\boxed{
\text{Emotion State}

\]

並由：

\[

其中：

\[
\text{Emotion}

\[
\text{Memory Equivalent}
\]

不是資料量；

\[
\text{Current Judgment Quantity}
\]

不是全部記憶量；

\[
\text{Peak}
\]

不是絕對上限。

# 二十一、本階段研究的重要新增命題

目前可以先保留以下工作性命題：

### 命題一：記憶連續性命題

\[
\boxed{
\text{Record}
\neq
\text{Memory}
}
\]

真正的記憶功能需要使過去持續參與現在的結構與選擇。

### 命題二：記憶當量命題

\[
\boxed{
\text{Memory Equivalent}
}
\]

可作為衡量過去結構在當前條件下實際作用程度的工作性概念。

### 命題三：記憶不變詞命題

只要構築允許跨時間與跨形式持續參照，就需要某種 Persistent Reference；記憶性結構因此成為可能的不變詞之一。

### 命題四：當下判斷量命題

\[
\boxed{
\text{Stored Information}
\neq
\text{Current Judgment Quantity}
}
\]

### 命題五：情緒觸發命題

\[
\boxed{
\text{Emotion}
\rightarrow
\text{Memory Retrieval Priority}
}
\]

情緒可能是記憶重新進入構築的重要觸發因素，但並非唯一觸發因素。

### 命題六：峰值處理命題

\[
\boxed{
\text{Peak}
\neq
\text{Absolute Ceiling}
}
\]

超峰值狀態不應直接視為系統失敗，而應進入後續處理選擇。

### 命題七：記憶與真實性分離命題

\[
\boxed{
\text{Emotional Strength}
\neq
\text{Memory Validity}
}
\]

# 二十二、目前研究狀態

本報告中的「記憶當量」「當下判斷量」「多維情緒狀態」「情緒峰值」與「構築海馬體」目前均應標示為：

\[
\boxed{
\text{Working Concepts / Hypotheses}
}
\]

其中部分概念已與既有構築理論形成高度結構相容性，但仍不應在目前階段直接宣稱為完成的神經科學模型或經實驗驗證的心理學模型。

目前研究最穩定的部分，是概念之間的結構關係：

\[
\boxed{
\text{Past Structure}
\rightarrow
\text{Persistent Reference}
\rightarrow
\text{Memory Equivalent}
\rightarrow
\text{Current Judgment}
}
\]

以及：

\[
\boxed{
\text{Emotion State}
\rightarrow
\text{Priority / Trigger}
\rightarrow
\text{Memory Re-entry}
}
\]

後續研究可進一步檢驗：

1. 記憶當量是否能形成可操作的判定規則；
2. 當下判斷量是否可以形成可重現的量化或半量化尺度；
3. 情緒峰值是否需要固定類型，或應保持開放結構；
4. 超峰值後的處理是否可以被形式化；
5. 代理人輸出是否能以當量方式比較；
6. 上述結構是否可以在 AI 系統中實際運行而不造成記憶偏置與錯誤自我強化。

---

# 二十三、目前總結

本階段並未改變構築的核心定位。

相反地，它將構築原有的：

\[
\text{Thematic Invariance}
\]

\[
\text{Adaptive Construction}
\]

\[
\text{Invariant}
\]

\[
\text{Continuation}
\]

進一步延伸至：
